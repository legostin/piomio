# Интеграции

Всё, к чему Piomio подключается и что умеет делать для человека (погода, календари, карты, валюты…), живёт здесь —
по папке на интеграцию. Хаб загружает каждую папку как встроенный плагин и показывает её в каталоге плагинов.
Чтобы добавить интеграцию, работать нужно только в её папке: хаб, веб-интерфейс и приложения менять не надо.

## Добавить

```bash
npm run new:integration -- air-quality
```

Команда копирует [`_template`](_template) (готовая интеграция: восход и закат карточкой в чате и источник сигналов `sunrise`) в
`integrations/air-quality/`. Дальше — в этой папке:

1. `.piomio-plugin/plugin.json`: карточка в каталоге (категория, иконка, строка описания, пример запроса), хосты, к
   которым она ходит, виды карточек и настройки.
2. `.piomio-plugin/locales/en.json` и `ru.json`: каждый текст, который читает человек, на обоих языках.
3. `server/index.ts`: инструменты, которые вызывают агенты, и сигналы, которыми могут запускаться триггеры (в шаблоне это
   `sunrise`; см. раздел «Signals» в руководстве). `ui/src/index.tsx`: карточка, которую они показывают в чате.
4. `test/air-quality.test.ts`: тесты против подделки сервиса.

```bash
npx vitest run integrations/air-quality
npm run typecheck
npm run build:ui-plugins
```

Полное руководство (поля манифеста, инструменты, карточки, секреты, тесты) — [`_template/SKILL.md`](_template/SKILL.md).
Это же скилл `make-integration`, который хаб даёт агентам: попросите ассистента сделать интеграцию, которой ещё нет, —
он соберёт её так же у себя в рабочей папке и установит на ваш хаб, когда вы разрешите то, что она запрашивает.

Папки, чьи имена начинаются с `_`, — не интеграции.
