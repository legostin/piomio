Интеллект — то, чем думает агент. Своей модели у Piomio нет: он запускает официальные консольные программы разработчиков моделей, в которые ты входишь своим аккаунтом, на тарифе, который у тебя уже есть. У каждого агента свой список интеллектов по порядку: если первый ответить не может, берётся следующий.

## Три интеллекта

| Интеллект | Официальный CLI | Вход через |
|---|---|---|
| Claude Code | `claude` (`@anthropic-ai/claude-code`) | твой аккаунт Claude |
| Codex | `codex` (`@openai/codex`) | твой аккаунт ChatGPT |
| Kimi Code | `kimi` (`@moonshot-ai/kimi-code`) | твой аккаунт Kimi |

Каждый входит на собственной странице своего разработчика. Piomio только запускает вход самого CLI, а для Claude Code ещё передаёт ему код, который ты вставишь. Логин CLI хранит там же, где всегда, — в домашней папке пользователя, от которого работает Piomio. Сам Piomio эти токены не читает, не копирует и не хранит.

> Условия Anthropic не разрешают приложениям хранить токены Claude, поэтому токен из `claude setup-token` Piomio тоже не берёт. Если вставить такой в сообщение, хаб вырежет его раньше, чем его кто-то увидит, и нигде не сохранит, а ассистент вместо этого покажет карточку входа.

На Mac с приложением ChatGPT или Codex Piomio запускает самый новый Codex из найденных: тот, что в `PATH`, или копию внутри приложения. Новые модели сначала приходят в новые версии Codex.

## Вход из чата

На новом хабе, пока не работает ни один интеллект, в чате стоит карточка **Чтобы я мог отвечать, подключите интеллект**. В ней строки Claude Code, Codex и Kimi Code, у каждой кнопка **Войти**. Всё, что ты напишешь в это время, подождёт: ответ придёт, как только заработает хоть один интеллект.

Потом просто попроси: «подключи Codex», «войди в Claude Code заново», «подключи Kimi». Ассистент покажет в чате карточку входа. Ничего не нужно набирать в терминале.

### Codex и Kimi Code: одноразовый код

1. Нажми **Войти**. Через пару секунд в карточке появятся кнопка **Открыть** и код.
2. Нажми **Открыть** и войди на странице OpenAI (или Kimi).
3. Введи там код из карточки. Код Codex действует 15 минут, Kimi — 30; до какого времени, видно в карточке.
4. Карточка сама проверит вход и свернётся в одну строку: «Codex: вход выполнен».

Вводи код только на странице, открытой из карточки, и никому его не сообщай.

### Claude Code: вставить код обратно

1. Нажми **Войти**, потом **Открыть** — откроется страница входа Claude.
2. Войди. Страница покажет код: скопируй его.
3. Вставь код в поле карточки (**Код со страницы**), а не в чат, и нажми **Продолжить**.

На всё есть 15 минут. Потом карточка проверит вход и станет зелёной.

Если вход не удался или время вышло, карточка скажет почему и предложит **Попробовать снова**. **Отменить** останавливает начатый вход. У интеллекта, в который уже вошли, есть **Войти заново** — чтобы сменить аккаунт.

### Если CLI не установлен

Приложение для компьютера и сервер, установленный через `install.sh`, умеют ставить недостающий CLI сами. Тогда в строке написано **Не установлен**, а кнопка называется **Установить и войти**: хаб поставит CLI из его официального npm-пакета в `<data>/tools` (разовая загрузка на несколько сотен МБ), и вход начнётся сам.

CLI, который ты поставил сам, главнее: хаб первым находит его в `PATH` твоей login-оболочки. Поэтому Claude Code или Codex, которыми ты уже пользуешься и в которые уже вошёл, работают как есть, без второго входа. Только что что-то поставил? Нажми в карточке **Проверить снова**.

Запускаешь из исходников? Задай `PIOMIO_INSTALL_CLIS=1`, чтобы хаб так же ставил CLI сам, или поставь их вручную.

### На сервере

Хаб, установленный через `install.sh`, работает от пользователя `piomio`, и агенты думают тем, во что вошёл этот пользователь. Кнопка **Войти** в чате работает и там. Если удобнее терминал, войди сам от этого пользователя:

```bash
sudo -iu piomio
curl -fsSL https://chatgpt.com/codex/install.sh | sh
codex login --device-auth
```

Claude Code: `curl -fsSL https://claude.ai/install.sh | bash`, потом `claude` и его вход. Kimi Code: `curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash`, потом `kimi` и `/login`. Piomio заметит вход в течение минуты, перезапускать ничего не надо. Входи от `piomio`, а не от root, иначе хаб вход не увидит. Подробнее — на странице [На сервере с Linux](server.md).

### Каждый компьютер входит сам

Вход принадлежит компьютеру, на котором работает CLI. Когда ты подключаешь ещё один компьютер, его Claude Code, Codex и Kimi Code тоже становятся интеллектами и думают по входу на том компьютере. В их карточке написано «Этот интеллект входит на своём компьютере.» Piomio никогда не переносит вход с одного компьютера на другой. См. [Машины и другие компьютеры](machines.md).

## Страница «Интеллект»

Открой **Настройки** → **Интеллект**. Там все интеллекты, которые знает хаб, — на этом компьютере и на других твоих, у каждого статус:

| Статус | Что значит |
|---|---|
| **готов** | установлен, вход выполнен, лимит не исчерпан |
| **нужен вход** | CLI есть, но вход не выполнен: нажми **Войти** |
| **нужна настройка** | API-интеллекту не хватает ключа, сервера или модели |
| **недоступен** | CLI не запускается, обычно потому, что не установлен |
| **лимит до …** | упёрся в лимит тарифа; до этого времени агенты его пропускают |
| **не проверен** | ещё не проверяли |
| **не подключён** | агент ссылается на интеллект, которого у хаба сейчас нет: плагин выключен или компьютер не в сети |

Под названием видно модель, версию, где он работает и когда его проверяли. **Проверить все** и **Проверить** смотрят заново; **Сбросить лимит** забывает записанный лимит, и агенты попробуют интеллект раньше времени сброса. Ниже, в **Как подключить**, есть карточки входа для Claude Code, Codex и Kimi Code.

То же можно в чате: «какие у нас есть интеллекты?», «проверь Codex ещё раз», «у Claude лимит уже должен был кончиться, попробуй».

## Какой интеллект отвечает

У каждого агента интеллекты идут по порядку (**Интеллект по порядку предпочтения** в настройках агента). Можно и просто сказать: «пусть Ада сначала берёт Codex».

- **В чате** агент думает интеллектом, который ты для него выбрал, а если не выбирал — первым в списке. Если тот сейчас ответить не может (нет входа, исчерпан лимит), отвечает следующий готовый. Если интеллект выбирал ты сам, чат вернётся к нему, как только тот сможет; если нет — чат остаётся на том, к которому перешёл, пока ты не поменяешь интеллекты агента.
- **Задачи, каналы и расписания** получают интеллект под каждое дело: хаб выстраивает интеллекты агента в порядке, который подходит этому делу (мелкое поручение, обычная работа или трудная задача; код или текст), каждому со своей моделью и глубиной, и берёт первый, который может работать сейчас.
- **Когда лимит исчерпан у всех**, чат так и скажет и назовёт время, когда продолжит. Задача подождёт и начнётся снова в момент сброса.
- **Когда интеллект агента просто временно не на связи** (хаб переходит на другой компьютер, компьютер уснул, плагин перезапускается), в чате вместо ошибки видна строка статуса: «Нет связи с интеллектом · отвечу, как только она вернётся». Агент ответит, как только интеллект вернётся, а строка исчезнет сама. **Стоп** прекращает ожидание. Только если связи нет полчаса, чат скажет, что не может начать. Задача так же тихо ждёт свой интеллект.
- **Интеллект на компьютере хаба заодно означает тот же интеллект на других твоих компьютерах**, после собственного списка агента. Работа уйдёт в Codex на ноутбуке, когда Codex хаба занят или упёрся в лимит.
- **Агент, у которого ни один интеллект не настроен**, думает любым другим интеллектом хаба, начиная с самого быстрого, — если только он не привязан к определённым компьютерам.

Сколько задач идёт на одном интеллекте одновременно, задаёт **Параллельных сессий на интеллект** в **Настройки** → **Общие** → **Интеллект** (по умолчанию 2). Остальные ждут в очереди, а твои собственные разговоры не ждут никогда.

## Модели и глубина

В чате с агентом кнопка интеллекта в шапке открывает меню **Как думает «Ада»**:

| Пресет | Что делает |
|---|---|
| **Авто** | отвечает сразу на самом быстром интеллекте, под каждую задачу выбирает интеллект и глубину |
| **Быстро** | быстрые ответы, лёгкие размышления |
| **Сбалансированно** | для повседневных дел |
| **Глубоко** | дольше думает над сложным |

Новый агент думает в режиме **Авто**. Каждый интеллект превращает пресет в свои модель и глубину. У Claude Code, например, **Быстро** — это Sonnet с низкой глубиной, **Сбалансированно** — Opus со средней глубиной, **Глубоко** — Opus с очень высокой глубиной (с высокой, если CLI её не знает). **Точная модель и глубина** даёт выбрать **Модель** и **Глубину рассуждений** самому. Уровни берутся из установленного CLI; если у интеллекта нужного уровня нет, берётся ближайший из тех, что есть.

В том же меню список интеллектов агента: выбранный становится первым для чата. **По-разному для задач, каналов, расписаний** открывает короткий чат с агентом, чтобы настроить каждый вид работы отдельно; вид без своего выбора думает как в чате. **Подключить ещё интеллект** открывает страницу «Интеллект».

Агенты на Codex всегда работают на его обычной скорости. Пресет **Быстро** — это только модель и глубина, а собственный быстрый режим Codex (Fast), который быстрее расходует план, для агентов выключен, даже если он включён в твоём `~/.codex/config.toml`.

Между твоими сообщениями Claude Code или Codex этого чата остаётся запущенным ещё 10 минут, максимум для трёх чатов на интеллект, поэтому следующий ответ начинается быстрее. Пока он ждёт, токены не тратятся.

### /brain и /effort

На эти команды хаб отвечает сразу, без модели:

| Пишешь | Что происходит |
|---|---|
| `/brain` | карточка с интеллектами агента и тем, которым он думает сейчас |
| `/brain codex` | агент думает в этом чате через Codex (только если тот готов) |
| `/effort` | карточка с уровнями: четыре пресета и собственные уровни интеллекта |
| `/effort глубоко`, `/effort высокая` | ставит этот уровень |

Названия понимаются и по-русски, и по-английски. В Telegram ответ приходит словами. В групповом чате пиши эти команды в личном чате нужного агента.

## API-ключи как интеллект

По умолчанию агенты думают только через CLI, на твоих тарифах. Хаб, запущенный с `PIOMIO_API_KEYS=1` (одинаково на каждом компьютере, где работает хаб), разрешает думать и через обычные API-ключи:

- API-интеллект: `api:anthropic`, `api:openai`, `api:openrouter` и `api:custom` для Ollama, LM Studio, vLLM или любого OpenAI-совместимого сервера; есть и Kimi, DeepSeek, GLM, Qwen, Gemini, Grok, Mistral и Groq;
- Codex с ключом OpenAI API;
- API-ключи для Claude Code и Codex на других твоих компьютерах ([Машины и другие компьютеры](machines.md)).

Чтобы дать ключ, скажи «подключи OpenRouter» или вставь ключ прямо в сообщение: хаб узнает привычные форматы, вырежет ключ из сообщения и положит его в хранилище. На странице «Интеллект» появится карточка **API-ключи** с полем для каждого провайдера, и карточка настройки предложит то же самое. Ключи лежат в хранилище под такими id:

| id в хранилище | Для чего |
|---|---|
| `anthropic_api_key` | `api:anthropic` |
| `openai_api_key` | `api:openai`, Codex по ключу |
| `openrouter_api_key` | `api:openrouter` |
| `custom_llm_api_key` | `api:custom`, только если твоему серверу нужен ключ |

Остальные устроены так же: `moonshot_api_key`, `deepseek_api_key`, `zhipu_api_key`, `qwen_api_key`, `gemini_api_key`, `xai_api_key`, `mistral_api_key`, `groq_api_key`.

### Свой сервер моделей

`api:custom` ходит на `http://127.0.0.1:11434/v1` (Ollama) с моделью `llama3.1`, пока ты их не сменишь: попроси ассистента или задай **Адрес OpenAI-совместимого сервера** и **Модель OpenAI-совместимого сервера** в настройках плагина **API-интеллект**. Сервер на том же компьютере доступен всегда. Сервер в другом месте твоей сети нужно разрешить: добавь его хост в **Дополнительные разрешённые хосты** в **Настройки** → **Общие** → **Интеллект** (`brainEgressAllow`). Адрес у него частный, поэтому хост нужен ещё и в `egressPrivateAllow`, для которой поля пока нет ([Настройки и переменные окружения](settings.md)).

### Ключи, которым флаг не нужен

Ключам, которые не интеллект, `PIOMIO_API_KEYS` не нужен: веб-поиск (`brave_api_key`, `tavily_api_key`), токен Telegram-бота и распознавание голосовых (ключ Groq или OpenAI либо свой сервер Whisper) работают на любом хабе.

Что интеллекту можно делать на своём компьютере, песочница и автомод — в разделе [Подтверждения и автомод](approvals.md).
