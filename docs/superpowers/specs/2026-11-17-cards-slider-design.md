# Слайдер карточек (`show_cards`)

Агент подбирает варианты (заведения, товары, программы, тарифы) и показывает их не списком в тексте, а лентой
карточек. Карточка раскрывается в страницу позиции на весь экран.

## Что видит человек

- **Лента в ответе агента.** Горизонтальный слайдер: свайп на телефоне, стрелки на десктопе, точки снизу. На карточке
  фото, название, строка под ним, цена и рейтинг, бейдж («Лучший выбор») и до трёх тегов. Одна позиция показывается
  одной карточкой без ленты.
- **Страница позиции.** Нажатие открывает позицию на весь экран: галерея фото (фото открывается в просмотрщике),
  «почему стоит», описание (Markdown), характеристики, плюсы и минусы, адрес и часы с картой и ссылкой на маршрут,
  ссылки («Сайт», «Купить»). Пустые блоки не показываются. Соседняя позиция листается стрелками в шапке и клавишами
  ← →; Escape закрывает.
- **«Выбрать».** Кнопка на странице позиции отправляет название как сообщение человека (как быстрые ответы) и
  помечает карточку выбранной. Выбрать можно другую позицию позже: метка переходит, уходит новое сообщение. Агент
  выключает кнопку (`pick: false`), когда это просто показ.
- **Своя страница агента.** Позиция с `page` открывает страницу агента (`page_create`) вместо готовой: для случаев,
  когда готового набора блоков мало.

## Контракт

`packages/shared/src/types.ts`:

```ts
| { type: "cards"; title?: string; items: CardItem[]; pick?: boolean; chosen?: number }

interface CardItem {
  title: string;
  subtitle?: string;
  images?: ImageItem[];          // первая — на карточке; src как у show_images
  price?: string;
  rating?: number;               // 0–5
  badge?: string;
  tags?: string[];
  why?: string;
  text?: string;                 // Markdown
  specs?: Array<{ label: string; value: string }>;
  pros?: string[];
  cons?: string[];
  address?: string;
  hours?: string;
  lat?: number;
  lon?: number;
  links?: Array<{ label?: string; url: string }>;
  pageId?: string;
}
```

`pick` хранится только как `false`; `chosen` — индекс выбранной позиции.

## Хаб

- **Инструмент `show_cards`** (`packages/core/src/tools/card-tools.ts`, владелец core, `effect: "read"`): 1–12
  позиций, обязательное только название. Картинки — `url` или `path` в рабочей папке, по тем же правилам, что у
  `show_images`; не больше 8 на позицию. Строки обрезаются, ссылки только http(s), `page` находится по id или
  названию. Ошибки в позициях возвращаются модели, ничего не показывается. Часть уходит через `showToPerson`: из
  задачи карточки видны и в диалоге, который её начал.
- **Выбор:** `POST /api/messages/:id/pick { part, index }` → `runner.pick`: ставит `chosen` и отправляет название
  сообщением человека. Модель получает перед ним строку контекста с кратким описанием позиции, чтобы выбор был понятен
  и диалогу, который карточки не составлял.
- **Пересказ и превью:** `[showed cards: A; B; chosen: B]` в continuity и групповом чате, в превью чата — название
  ленты или первой позиции.
- **Картинки:** адреса картинок карточек входят в `partPictures` (проверка исходящих запросов, как у `show_news`).
- **Каналы (Telegram):** позиция с фото уходит фотографией с подписью (название, цена, рейтинг, ссылка). Позиции без
  фото в канал не уходят; описание инструмента говорит об этом агенту.
- **Промпт:** несколько вариантов на выбор — `show_cards`; сложное сравнение — страница.

## Веб (он же чат в iOS и десктопе)

- `pages/chat/CardsCard.tsx`: лента и карточка. Механика ленты (активный слайд, края, стрелки, точки) выносится из
  `ImagesCard.tsx` в общий хук `lib/strip.ts` и используется обоими.
- `pages/chat/CardDetail.tsx`: страница позиции в `FullscreenPanel`; позиция с `pageId` открывает `PageViewer`.
- `lib/cards.ts`: чистая логика (подпись ссылки по хосту, элементы галереи для просмотрщика, место позиции как
  карта) с тестом.
- `lib/fullscreen.ts`: общий счётчик «окно занято целиком» для страницы агента, страницы позиции и карты на весь
  экран: карта поверх страницы позиции не возвращает шапку и поле ввода, пока страница открыта.
- Строки в `i18n/{en,ru}.ts`; шаг `show_cards` в живой строке читается словами.
